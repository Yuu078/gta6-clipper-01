A vertical GTA 6 clip cut by an AI agent from Rockstar's official launch trailer: the street-action run that peaks in the dirt-bike mid-air jump, replayed in slow motion, then make.fun's pitch over the Vice City sunset. `main.ts` hands the gate the video's address from `VIDEO.json`; the house reads the video's views on YouTube, and the top 20 most-watched clips share the $500 bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
